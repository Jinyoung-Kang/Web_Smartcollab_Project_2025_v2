# ADR-0008 모의 결과 대신 설명 가능한 기능만 노출

## 배경
v1 의 "요약"은 파일 앞 150자를 잘라 `[요약 결과]` 라고 붙인 모의 결과였고, 번역 API 키가 없으면 `[MOCK] (en) 원문` 을 번역 결과처럼 보여 주었습니다. 사용자는 결과가 진짜인지 구분할 수 없습니다.

## 결정
- 요약: 외부 서비스 없이 동작하는 **단어 빈도 기반 추출 요약** (문장 분리 → 조사 제거 토큰화 → 빈도 가중치 → 길이 보정 점수 → 상위 문장을 원문 순서로). 원문 문장만 반환하고 화면에 "생성형 AI 요약이 아님"을 명시
- 번역: DeepL 키가 있을 때만 활성화. 키가 없으면 서버는 503 `FEATURE_DISABLED`, 화면은 버튼을 비활성화하고 이유를 표시
- 인증은 DeepL 의 헤더 방식(`Authorization: DeepL-Auth-Key`)으로, 긴 문서는 줄 경계로 나눠 한 번에 전송

## 결과
- 결과의 출처가 명확함. 생성형 요약이 필요하면 같은 API 뒤에 LLM 구현을 추가할 수 있음
