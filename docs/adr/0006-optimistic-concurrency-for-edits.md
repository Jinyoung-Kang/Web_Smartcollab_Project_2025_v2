# ADR-0006 텍스트 편집은 낙관적 동시성 제어

## 배경
v1 은 같은 문서를 두 사람이 편집하면 나중 저장이 앞사람의 변경을 조용히 덮어썼습니다(lost update). "실시간 공동 편집" 코드가 있었지만 연결·구독되지 않는 죽은 코드였습니다.

## 선택지
1. 비관적 잠금(편집 중 잠금) — 편집 세션이 길어 잠금 해제 누락·대기 문제
2. CRDT 기반 실시간 공동 편집 — 가치가 크지만 이 프로젝트 범위를 넘음
3. **낙관적 잠금** — 편집 시작 버전을 들고 저장, 달라졌으면 거절

## 결정
- `GET /content` 가 현재 `versionId` 를 주고, `PUT /content` 는 `baseVersionId` 가 현재 버전과 다르면 409
- 검사와 저장 사이의 경쟁은 JPA `@Version` 이 막음 (두 요청이 동시에 검사를 통과해도 한쪽 커밋이 실패 → 409, 방금 쓴 blob 은 롤백 정리)
- 화면: "최신 내용 불러오기(내 편집본은 클립보드) / 내 내용으로 새 버전 저장" — 어느 쪽이든 모든 버전은 기록에 남음

## 결과
- 데이터 손실 없음, 충돌 시에만 사용자가 판단. 실시간 공동 편집은 향후 과제로 명시
