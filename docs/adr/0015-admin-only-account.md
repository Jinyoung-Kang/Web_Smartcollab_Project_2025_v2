# ADR-0015 관리 전용 계정 — 환경 변수로 만들고, 계정 목록·삭제만 하며 파일·대화에는 닿지 않음

## 배경
공개 데모에서 가입한 계정을 정리할 방법이 없었습니다. 요구는 "관리자는 모든 계정의 아이디·소속 팀·드라이브 사용량·가입일을 보고, 계정을 골라
삭제(탈퇴 처리)할 수 있되, 그 계정의 파일·대화는 볼 수 없다"입니다. v1 에는 관리자 API 가 있었지만 로그인한 누구에게나 비밀번호 해시가 담긴
User 엔티티를 그대로 주어 v2 에서 지웠습니다(`AccessControlTest`).

## 선택지
1. 계정 만들기: Flyway 마이그레이션에 계정을 넣기 / 기존 계정을 DB 에서 관리자로 올리기 / **환경 변수(ADMIN_USERNAME·ADMIN_PASSWORD)로 기동 때 만들기**
   — 마이그레이션은 공개 저장소에 비밀번호 해시가 남고, DB 직접 수정은 운영 DB 방화벽을 열어야 합니다.
2. 관리자 범위: 일반 기능 + 관리 화면 / **관리 화면만(드라이브·팀·채팅 없음)** — 파일·대화를 볼 수 없다는 요구를 권한 규칙의 예외가 아니라 구조로 지킵니다.
3. 팀장인 계정을 지울 때: 거절(탈퇴와 같음) / 이끄는 팀도 삭제 / **가장 먼저 들어온 멤버에게 넘기고, 멤버가 없으면 팀 삭제**
   — 관리자는 팀장을 대신 넘길 수 없어 거절하면 지울 수 없고, 팀을 지우면 다른 멤버의 자료가 사라집니다.
4. 체험 계정: 목록에서 숨김 / **목록에 표시하고 삭제 불가** — 매일 초기화되며 지우면 공개 데모가 깨집니다.

## 결정
- 역할 `ADMIN` 을 더합니다(`users.role` 이 이미 문자열이라 스키마는 그대로). 아이디가 설정돼 있으면 기동 때 계정을 만들고, 비밀번호가 바뀌었으면 새 해시로 바꿉니다.
  비밀번호가 12자 미만이면 기동을 멈추고, 같은 아이디의 일반 계정이 있으면 관리자로 올리지 않습니다(먼저 가입한 사람이 관리자가 되는 것을 막음).
- 역할이 ADMIN 이어도 **지금 설정된 아이디일 때만** 로그인·관리 API 를 허용합니다. 설정을 지우면 관리 기능이 꺼집니다.
- 로그인 토큰에 역할을 넣고 경로 규칙으로 나눕니다 — `/api/admin/**` 는 관리자, 그 밖의 API·WebSocket 은 일반 사용자(역할이 없는 예전 토큰은 일반 사용자).
  관리 API 는 `AccessPolicy.requireAdmin` 으로 DB 를 한 번 더 확인합니다(ADR-0005 의 "권한은 한 곳에서").
- 목록 응답은 아이디·이름·소속 팀 이름(팀장 여부)·개인 드라이브 사용량·한도·가입일·체험 계정 여부만 담습니다. 새 `admin` 모듈은 다른 모듈의 리포지토리를
  쓰지 않고 user·team·file 모듈의 서비스를 거칩니다(ADR-0010, 기준선 그대로).
- 삭제는 한 트랜잭션에서 팀장 위임(체험 계정은 받지 않음 — 매일 초기화가 체험 계정이 이끄는 팀을 지움, H-3) → 탈퇴와 같은 정리(`AccountDeleting` 이벤트)를 하고,
  커밋 뒤 그 계정의 토큰과 실시간 연결을 끊습니다. 보안 로그에 `account-deleted-by-admin` 을 남깁니다.

## 결과
- 관리자도 파일·폴더·채팅 API 는 403 이라, 관리자 계정을 빼앗겨도 계정 정보와 삭제까지만 닿습니다. 삭제는 되돌릴 수 없으므로 화면에서 아이디를 입력해야 확인됩니다.
- 관리자 비밀번호는 코드·문서·저장소 어디에도 없고 배포 설정에만 있습니다. 비밀번호를 바꾸면 재기동이 필요합니다.
- 팀장 위임은 팀장 팀 수 상한(S-10) 안의 멤버를 먼저 고르고, 모두 상한이면 상한을 넘겨서라도 넘깁니다(팀 자료를 지우는 것보다 낫기 때문).
- 근거: `AdminAccountTest`(ADM-01~09)·`AdminAccountInitializerTest`(ADM-10)·`DemoProtectionTest`(ADM-11)·`AuthorizationMatrixTest`(ADM-02)·`AccessControlTest`,
  프론트 `AdminPage.test`·`App.test`(ADM-12), E2E `admin.spec.ts`(ADM-13).
