# ADR-0016 PDF 번역은 서버가 뽑은 글자를 보냄 — Apache PDFBox, 글자가 거의 없는 PDF 만 원본

## 배경
ADR-0011 은 PDF 를 원본 그대로 Claude 에 보냈습니다(쪽마다 이미지 + 글자). 운영에서 거의 한국어인 8쪽 PDF 의 번역이 계속 틀렸습니다 —
한국어 번역은 문서 대신 용어표 JSON(AI-12), 고친 뒤에는 영어 번역이 한국어 원문을 거의 그대로 옮긴 글(AI-13)이었습니다.
같은 코드로 재현하니 영어 번역 3번 중 2번이 원문 그대로이거나 "단계: Step:"처럼 원문과 번역을 나란히 적었고(한글이 글자의 21~51%),
서버는 원문 글자를 몰라 결과가 번역인지 가려낼 수 없었습니다. 입력도 쪽 이미지 때문에 15,349 토큰이었습니다.

## 선택지
1. 프롬프트만 고치고 다시 요청 — 원인(무엇이 원문인지 서버가 모름)이 그대로이고, 같은 PDF 에서 실패가 3번 중 2번이라 다시 요청해도 자주 실패
2. 기능 끄기(PDF 번역 비활성화) — 사용자가 고르지 않은 마지막 수단
3. **서버가 PDF 에서 글자를 뽑아 텍스트로 보냄** — 원문을 알게 되어 길이·글자 체계로 결과를 확인할 수 있고, 입력이 약 1/5
   - 라이브러리: JDK 에 PDF 해석기가 없음 → **Apache PDFBox 3.0.8**(Apache 2.0, OSV 공지 없음, commons-logging 은 Spring 과 공유)

## 결정
- 번역만 바꿉니다. PDF 는 `PdfText` 로 쪽 순서대로 글자를 뽑아(쪽 사이 빈 줄) 텍스트 문서처럼 보냅니다. 요약은 원본 PDF 그대로입니다(문제가 없었음).
- 절반 넘는 쪽에 글자가 10자 미만(스캔한 그림 등)이거나, 읽을 수 없는 글자(대체 문자·사용자 정의 영역)가 10% 를 넘거나, 열 수 없는 PDF 는 원본을 보냅니다.
- 사용자 파일을 서버가 해석하므로 Word(H-1)와 같은 대비를 둡니다. 그림이 아닌 스트림을 필터마다 상한 있는 출력으로 풀어 보고 합계가 64MB 를
  넘으면 끝까지 풀지 않고 원본을 보냅니다 — PDFBox 는 쪽 내용이 Flate 스트림 하나일 때만 흘려 읽고, 그 밖(내용 배열·다른 압축)은 통째로 메모리에
  풀었습니다(쪽 내용이 배열인 폭탄: 300MB 로 풀리면 329MB 할당, 600MB 면 512MB 힙에서 OOM). 사전 검사 뒤에는 0.1~0.2초·할당 3MB 이하로 멈춥니다. 뽑은 글자는 편집기 한도(2MB)에서 멈추고 413.
- 결과 확인(ADR-0011 의 불완전 판정에 더함): 대상 언어에 쓰지 않는 글자(영어: 한글·가나·한자, 일본어: 한글, 중국어: 한글·가나, 한국어: 가나)가
  결과 글자의 10% 를 넘고 20자 이상이면 번역이 아닌 것으로 봅니다. 빈·불완전한 답은 한 번 다시 요청합니다(두 요청의 토큰을 합쳐 정산).
  처음에는 출력이 한도의 1/4 이하일 때만 다시 요청했으나, 원문과 번역을 나란히 적은 답은 오히려 길어 이 조건을 뺐습니다.
  출력 한도에서 잘린 답은 지금처럼 413 이고 다시 보내지 않습니다.
- 프롬프트에 "원문 옆에 번역을 적지 말고, 대상 언어로만"을 더했습니다.

## 결과
- 같은 PDF 실측(qa/results/ai/AI-13): 영어 4/4·한국어 3/3·일본어·중국어 각 1/1 이 문서 전체 번역(영어 결과의 한글 0%), 다시 요청 0번.
  입력 15,349 → 약 3,030 토큰, 번역 1번 약 $0.003 → 약 $0.002(출력이 비용 대부분).
- 표·도형 배치는 글자 순서로만 전해집니다(원본 PDF 를 보낼 때도 결과는 글이었음). PDFBox 가 쪽 번호를 머리글에 붙여 읽는 곳이 있습니다("2e-Friend Expert").
- 스캔 PDF 는 예전 경로라 AI-13 같은 결과가 남을 수 있으나, 글자 체계 확인과 다시 요청은 원본 PDF 에도 적용됩니다.
- 근거: `PdfTextTest`(쪽 순서·스캔·손상·글자 수 상한·압축 폭탄 두 모양), `DocumentToolsTest`(PDF 번역은 텍스트, 스캔은 원본, 요약은 원본),
  `ClaudeDocumentAiTest`(글자 체계 확인·다시 요청·토큰 합산).
