# 개인·팀 드라이브 기능 점검 (브라우저)

[qa/scripts/feature-walkthrough.mjs](../../scripts/feature-walkthrough.mjs) — 데모 모드 임시 스택(`sc-test`, 8090)에서 Chrome 으로 실제 화면을 조작합니다.
AI 키가 있는 설정(요약 effort low · 번역 medium)이라 요약·번역은 실제 Claude 를 부릅니다.

## 점검용 파일 (개인 드라이브·팀 드라이브에 각각 새 폴더를 만들어 한 번에 올림)

| 파일 | 형식 | 미리보기에서 기대하는 것 | 번역 언어 |
|---|---|---|---|
| 보고서.pdf | 2쪽 PDF(한국어) | 브라우저 내장 PDF 뷰어 | 영어 |
| 입사 안내.docx | Word | 로컬 저장소라 Office 뷰어 대신 안내(설계대로), 요약·번역 도구 | 중국어(간체) |
| 요구사항.csv | CSV | 본문 | 일본어(행 수 유지 확인) |
| 회의록.md | Markdown(문서 속 지시 문장 포함) | 본문 | 영어 |
| 설정.json | JSON | 본문 | 일본어 |
| 사진.png | 이미지 | 이미지(요약·번역 도구 없음) | - |

## 결과 — 최종 실행 63개 항목 모두 통과 ([results.json](results.json))

| 기능 | 개인 | 팀 | 확인한 것 |
|---|---|---|---|
| 폴더 만들기·여러 파일 올리기 | 1/1 | 1/1 | 6개 동시 업로드 |
| 미리보기 | 6/6 | 6/6 | PDF 는 보기 주소가 `application/pdf` 200, 이미지 크기, 텍스트 본문 |
| 내려받기 | 6/6 | 6/6 | 파일 이름·SHA-256 이 올린 파일과 같음 |
| AI 요약 | 5/5 | 5/5 | 요약 문단 + 핵심 항목 + 모델·전송 안내 |
| 번역 | 5/5 | 5/5 | 결과 패널·공급자 안내, 정정 흔적·문서 표기·코드 울타리 없음, CSV 행 수 |
| 편집 → 저장 → 버전 기록 → 새 버전 요약 → 내려받기에 반영 | 4/4 | 4/4 | 이미지에 요약 단추 없음 포함 |
| 공유 링크(비밀번호·1회) → 로그인 없이 내려받기 | 2/2 | 2/2 | 틀린 비밀번호 거절, SHA 일치, 1회 뒤 "링크를 사용할 수 없습니다" |

| 팀 채팅으로 보내기 · 권한 | 결과 |
|---|---|
| 메시지 보내기 → 다른 멤버(이도윤) 화면에 실시간 표시 | 통과 |
| 파일 첨부해 보내기 → 보낸 사람·받는 사람 모두 파일 카드 | 통과 |
| 받은 파일 미리보기·AI 요약(팀 멤버 권한) | 통과 |
| 받은 파일 내려받기 | 통과(SHA 일치) |
| 팀 밖 사용자의 팀 파일 내려받기·요약·번역, 남의 개인 파일 내용 | 모두 404 |

콘솔에 남은 403·410 은 공유 링크에 틀린 비밀번호를 넣고(403), 1회를 쓴 뒤 다시 연(410) 확인에서 나온 의도한 응답입니다. 5xx 는 없었습니다.

## 점검에서 나온 것

| 무엇 | 처리 |
|---|---|
| **[AI-11]** PDF 요약에 일본어 조사가 섞임("증가분**の** 대부분은") — 첫 실행에서 발견, 같은 PDF 10번 요약하면 5번 | 프롬프트("한글로만") 4/10, effort medium 2/10 로 줄지 않아 한글 바로 뒤의 "の"를 "의"로 고침 → 0/10 ([../ai/summary-script-before-AI-11.txt](../ai/summary-script-before-AI-11.txt), [after](../ai/summary-script-after-AI-11.txt)) |
| JSON 문서의 일본어 번역이 502("AI 가 빈 결과") — 첫 실행 2번, 바로 이어 API 로 2번 | **원인 미확인.** 같은 요청을 Anthropic API 에 직접(일반·스트리밍) 보내면 정상이었고, 앱을 다시 띄운 뒤 같은 번역 10번과 전체 점검 2번(4번)은 모두 성공. 다음에 생기면 원인을 볼 수 있게 빈 결과일 때 응답 구조(블록 종류·멈춘 이유·글자 수)를 로그로 남기도록 함 ([results-run1.json](results-run1.json)) |
| CSV 일본어 번역에서 사람 이름을 한글 그대로 둠(김하늘) — 이전 실측에서는 가타카나로 옮긴 적도 있음 | 결함으로 보지 않음(이름은 그대로 둬도 뜻이 바뀌지 않음). 기록만 |
