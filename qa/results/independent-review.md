## 검토자가 지적한 절차 문제와 조치

| 지적 | 조치 |
|---|---|
| concurrency.json C4 의 "팀장A" 표기는 팀장이 없을 때도 A 로 적는 스크립트 기본값이라 오해를 부름 | 스크립트가 "없음"을 적도록 고침. 이전 결과 파일에 주석(`_note`) 추가 |
| multipart-edge.mjs 에 NUL 파일명 사례가 없음 | 사례 추가 |
| 업로드 중단 건의 요청 기록 상태는 400(클라이언트는 이미 끊김). "500" 은 ERROR 로그에만 해당 | 결함 설명을 "500 또는 ERROR 스택 로그"로 정정 |
| QA-06 의 "시드 중 12,900건에서 45건"은 결과 파일로 확인할 수 없음(앱 컨테이너를 다시 만들어 로그가 사라짐) | 결함 기록에서 이 수치를 빼고, 결과 파일이 있는 k6 수치와 InnoDB 보고서만 근거로 둠 |
| auth-session 의 실패 수에 무관한 2건(8KB 토큰 → Tomcat 헤더 한도 400)이 섞임 | 스크립트가 400·431 을 기대 동작으로 처리하도록 고침 |
| 시험은 첫 단언에서 멈춰 팀장 없는 최종 상태 자체는 블랙박스로만 확인됨 | 수정 뒤 시험이 최종 상태(소유자=팀장 표시를 가진 유일한 멤버)까지 확인하는지 통과 결과로 확인 |
