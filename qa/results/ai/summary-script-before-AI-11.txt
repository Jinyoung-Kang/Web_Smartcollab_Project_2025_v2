# [AI-11] 고치기 전 — 2쪽 PDF(사용량 보고서) 요약 10번씩, qa/scripts/ai-summary-script.mjs 와 같은 절차(콘솔 출력 요약)
# 기능 점검(개인·팀 드라이브)에서 PDF 요약에 "증가분の"이 섞인 것을 보고 반복 확인
요약 effort low(현재 설정): 5/10 — "증가분の 대부분은" 4번, "증가분の大部分은" 1번
요약 effort low + 프롬프트 "한글로만, 문서에 없는 일본어·한자 금지": 4/10 — 모두 "증가분の"
요약 effort medium: 2/10 — 모두 "증가분の"
→ 프롬프트·effort 로는 0 이 되지 않음. 모든 경우 한글 바로 뒤의 "の"(한국어 조사 "의" 자리)
